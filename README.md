# Kubernetes просто лабы

Практика к серии «Kubernetes просто»: от первого локального кластера до доступа к приложениям через Service и Ingress.

Каждая лабораторная закрепляет соответствующую теоретическую статью. Сначала разбираемся с назначением компонентов, затем запускаем команды, проверяем результат и выполняем самостоятельные задания.

## Для кого

Для тех, кто начинает изучать Kubernetes, умеет работать в терминале и знаком с контейнерами хотя бы на уровне образа и запуска приложения. Облачный аккаунт для первой лабы не нужен — используем локальный кластер kind.

## С чего начать

1. Прочитайте [первую теоретическую статью](https://habr.com/ru/articles/1082088/).
2. Установите Docker, kind и kubectl по ссылкам в [лабе 01](labs/01-cluster/README.md).
3. Пройдите лабораторную, проверяя результат каждого шага.
4. Выполните [задания](labs/01-cluster/tasks.md), затем сравните с [решениями](labs/01-cluster/solutions.md).

Клонировать репозиторий для первой лабы необязательно: команды можно выполнять из открытого README.

## Что есть в репозитории

## Статус проверки

Материалы подготовлены по официальной документации. Сквозной прогон на реальном стенде пока не зафиксирован. Примеры вывода иллюстративные; версии и время существования объектов будут отличаться. Карточка проверенного окружения находится в README первой лабы и заполняется после прогона.
